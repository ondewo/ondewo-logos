# Write in the ONDEWO voice

Produce copy that matches ONDEWO's voice and messaging.

## Load
Read `brand-kit/voice-and-tone.md` (voice principles, tone-by-context, grammar,
word lists, copy patterns) and `brand-kit/brand-foundation.md` (positioning,
audience, messaging pillars, proof points).

## Rules (from voice-and-tone.md)
- **Clear over clever; confident, not boastful; human; precise.**
- Active voice, present tense, "we" → "you".
- Sentence case for headlines and CTAs; no period on buttons.
- `ONDEWO` always all-caps. Tagline: *We automate your phone calls.*
- Prefer the shortest version that keeps the benefit.
- Avoid banned words (revolutionary, disruptive, magic, world-class without proof, …).
- Match tone to context (website / docs / error / social / sales — see the table).
- Speak to the right audience (business vs. technical vs. developer).

## Process
1. Identify: asset, audience, tone, length/format, and the one key message.
2. Draft **3 options**, varying angle (outcome-led / pain-led / proof-led).
3. Self-check each against the word lists and grammar rules; cut filler.
4. Recommend one and say why. Keep proof-point numbers as `‹confirm›` placeholders
   unless the user provided real figures.

## Output
Lead with the recommended option, then the alternatives, then any notes on
placeholders to fill. For longer pieces (landing page, email), provide the full
structured copy (eyebrow, H1, sub, body, CTA).
