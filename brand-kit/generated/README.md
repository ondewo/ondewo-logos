# Generated assets

Output folder for assets an agent or person creates from the templates. Safe to
commit campaign work here. **Never** put source-of-truth files here — those live in
`../templates/`, `../assets/`, and `../tokens/`.

Naming: `ondewo-<type>-<variant>-<theme>[-<WxH>].<ext>` (see `../assets/ASSET-INDEX.md` §D).
